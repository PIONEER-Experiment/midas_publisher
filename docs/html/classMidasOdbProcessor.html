◆ getProcessedOutput()

std::vector< std::string > MidasOdbProcessor::getProcessedOutput ( )
overridevirtual

Gets the processed output as a vector of strings.

Returns
Vector of strings representing the processed output.

The vector of strings is added to the circular buffer to be published. So an array of length 2 will add 2 entries to the circular buffer, for example. Empty arrays will not be added to the circular buffer and will therefore not but published.
